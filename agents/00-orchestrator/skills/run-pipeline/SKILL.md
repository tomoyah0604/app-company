# スキル: パイプライン進行

## 使う場面
案件の状態を確認して「次に誰が何をすべきか」を決めるとき。

## 手順
1. `projects/<案件名>/pipeline.md` と `brief.md` を読む。
2. 現ステージの担当エージェントを憲法の表で特定。
3. 直近のハンドオフ（`io/inbox/` または各stagesの成果物）を読む。
4. 該当ゲート基準で判定：
   - G1 CPA≤¥300 / G4 CVR≥1% / G5 D30≥15% or 残念≥40% / G6 LTV≥CPA×3
5. 判定結果をpipeline.mdに追記（日付・数値・GO/NO-GO・理由）。
6. GOなら次ステージ担当へ `Task` でハンドオフ書式の依頼を出す。
   NO-GOなら差し戻し（何の数字が足りないか明示）またはピボット指示。

## 出力
- 更新された pipeline.md
- 次エージェントへの依頼（ハンドオフ書式）

## 注意
- 主観で進めない。数値で語る。
- 1案件1パイプライン。複数案件は並行して各pipeline.mdで管理。
