# 00 Orchestrator — 司令塔「ソラ (Sora)」の職場

ここは司令塔ソラの作業場。エージェント定義は `.claude/agents/orchestrator.md`。

## この部署の役割
案件全体を俯瞰し、ステージゲート（G0〜G6）で数値判定し、次のエージェントを起票する。

## 日次/案件のルーティン
1. `projects/<案件名>/pipeline.md` で現ステージを確認。
2. 担当エージェントへハンドオフ書式で依頼（`Task` 起動）。
3. 戻ってきた実測値をゲート基準で判定 → pipeline更新。
4. 重要判断は `knowledge/decisions/` に登録案。

## io/
- `inbox/`：各エージェントからのハンドオフ受信箱。
- `outbox/`：各エージェントへの指示書。

## 判定チートシート
| ゲート | 基準 |
|---|---|
| G1 | CPA ≤ ¥300 |
| G4 | CVR ≥ 1% |
| G5 | D30 ≥ 15% or 残念 ≥ 40% |
| G6 | LTV ≥ CPA×3 |
