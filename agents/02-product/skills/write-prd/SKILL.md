# スキル: PRD作成

## 手順
1. `stages/01_idea/` と `knowledge/templates` のPRDテンプレを読む。
2. コア価値を1文で定義。
3. MVPスコープを「必須 / 後回し / やらない」に仕分け。
4. 課金設計（何を有料に、いつ課金導線を見せるか）を明記。
5. ユーザーフロー・主要画面・データモデルの骨子を書く。

## 出力
- `stages/02_prd/PRD.md`

## 章立てテンプレ
課題 / ターゲット / コア価値(1文) / MVP範囲(必須) / 後回し / やらない / 課金設計 / 画面一覧 / データモデル / 計測したい指標
