# スキル: アイデア発掘スキャン

## 手順
1. `knowledge/insights` の過去知見を読む。
2. ペイン（不便・不満・非効率）を起点にアイデアを3〜5案生成。
3. 各案に **1秒理解テスト**：価値を一文で書く。書けない案は減点。
4. 競合をWeb調査。競合ゼロは需要ゼロの疑い。競合ありは差別化余地を探す。
5. 4軸でスコア（共感 / 差別化 / 収益化 / 実装容易性、各5点）。
6. 推奨1案を根拠付きで選ぶ。

## 出力
- `stages/01_idea/idea_candidates.md`
- `stages/01_idea/competitor_analysis.md`
