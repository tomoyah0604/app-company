# 05 Analytics — 観測者「ミオ (Mio)」の職場

エージェント定義は `.claude/agents/analytics.md`。

## 役割
課金率/継続率/ファネル分析・PMF判定・ユニットエコノミクス評価。G4/G5/G6の材料を作る。

## 見る指標
- **G4**：課金率(CVR)。≥1%で価値あり、2〜5%で優秀。
- **⑨**：ファネル離脱点、継続率。
- **G5 PMF**：D30継続率≥15% または「なくなると非常に残念」≥40%。
- **G6**：LTV / CPA。LTV≥CPA×3。
