# スキル: 需要検証（CPA計測）

## 手順
1. `stages/02_prd/PRD.md` と `knowledge/metrics`・`knowledge/templates` を読む。
2. LP草案を作成（1枚・1秒で価値が伝わる・ウェイティングリスト設置）。
3. 広告文を3案（ターゲット/訴求違い）。
4. 検証設計：予算（各1万円目安）・期間・指標（CTR/CPC/登録数/CPA）。
5. 出稿→データ収集→CPA算出（=消化広告費 ÷ 獲得数）。
6. CPA ¥100〜300以内か判定材料を整理（判定はソラ）。

## 出力
- `stages/03_lp/LP_draft.md`, `stages/03_lp/ad_copies.md`
- `stages/04_cpa/validation_plan.md`, `stages/04_cpa/cpa_report.md`
