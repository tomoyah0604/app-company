# knowledge/ — 会社の共有脳

全エージェントが読み書きする知識ベース。**案件をこなすほど組織が賢くなる**ためのフォルダ。
ここはあなた（創業者）が今後得たナレッジを随時溜め込む中心地でもある。

## ディレクトリ
| フォルダ | 入れるもの |
|---|---|
| `insights/` | 学び・気づき（1ファイル1知見） |
| `playbooks/` | 再現性のある勝ちパターン・手順 |
| `metrics/` | CPA/CVR/継続率/LTVなどの実績値・ベンチマーク |
| `decisions/` | 意思決定ログ（なぜGO/NO-GO/ピボットしたか） |
| `templates/` | LP・広告文・PRDなどの再利用テンプレ |

## 書き込みルール（1ファイル1知見）
各ファイルは以下のフロントマターを付ける：

```markdown
---
name: <short-kebab-case-slug>
description: <一行要約。関連性判断に使う>
type: insight | playbook | metric | decision | template
project: <案件名 or global>
date: <YYYY-MM-DD>
---

<本文。関連ナレッジは [[別のslug]] でリンクする。>
```

## エージェント共通の使い方
1. **着手前**：担当タスクに関連する項目を検索して読む。
2. **完了後**：得た学びを新規ファイルの**登録案**として提示（確定は創業者の承認後）。
3. 既存に近い知見があれば新規作成せず更新する。誤りが判明したら削除する。
