## 撮影の共通ルール

**プロトタイプで実際に撮れる画面だけを使う**（未実装の機能の映像は作らない。CGやモックで足すこともしない）。

| 撮れる素材 | 操作 |
|---|---|
| 町の全景（朝・昼・夕・夜） | 右上の時間帯ボタンで切り替える。約1.5秒かけて光が変わり、夜は街灯・窓・星・ホタルが灯る |
| 75日チャレンジのカード | 画面上部。「75日チャレンジ」「今日 1/4」、進捗バー、「23日目 / 75日・のこり52日」 |
| 記録 → 移動 | 下のドックの習慣をタップすると、ボタンが「移動中…」になり、自分のキャラが道を歩いていく（カメラが追いかける） |
| 場所ごとの動き | ジム＝ダンベルとスクワット／図書館＝座って読書／カフェ＝ノートを書き、ときどきカップを持ち上げる／公園＝トラックを周回 |
| お祝い | 建物がぽよんと弾む、金色のリング、紙吹雪、バンザイ、花が5本生える。バナー「◯◯を記録しました 🔥N日連続！」の数字がカウントアップする。上部の「今日 N/4」も1つ増える |
| 友達の状況 | 名札（例:「ソウタ 🔥71」）。フレンドボタンを押すと一覧が開き、「◯人ががんばり中」（人数はシミュレーションで変わる）、「読書中」「筋トレ中」と表示される |
| プロフィールと応援 | 名札かキャラをタップするとシートが開く（例: ソウタ「71日目」「ジムで筋トレ中・35分前から」、4つの連続日数 ジム71・読書14・勉強40・ラン66）。拍手・ハートを押すと、ハートや星が浮かび、相手のキャラが跳ねる |
| 招待 | 「＋ 友達を町に招待する」を押すと、「招待リンクをコピーしました」のトーストが出る |

**修正後のサンプルデータ（台本の数値の前提）**
- 自分: 23日目。ジム22（※初期値を23から22に直す依頼中。`lp-copy-abc.md` の依存事項4）・読書22（今日は記録済み）・勉強8・ラン15
- 友達: ソウタ 71日目・ジム中🔥71／ユイ 🔥64（広場）／ナナ ラン中🔥55／ハル 読書中🔥52／ミオ 読書中🔥40／レン ラン中🔥38／タク 🔥15（広場）／メイ 勉強中🔥7／カイ ジム中🔥3

**撮影の仕様**
- 9:16の縦長、1080×1920で撮る。実機のfpsは未計測なので、**PCのブラウザを縦長の画面サイズにして画面録画**する（ヘッドレスで撮る場合は `?dtmax=` を使う）。
- **リポジトリにある `ss/*.png` は修正前（75週・🔥201/300）のままなので、使う前に撮り直す。**
- **A・Bでは、上部の「75日チャレンジ」のカードをトリミングで外すか、撮影用フラグ `?hud=minimal` で隠す。** カードが映ると、Cの「期限つきのチャレンジ」という訴求がA・Bにも混ざり、切り口の比較が成り立たなくなるため。Cではカードを主役として使う。
- **全カットの右下に「※画面は開発中のものです・人物はサンプル」を常に表示する**（町の友達はシミュレーションのため）。
- 音: アプリにはまだ効果音がない。各媒体の商用利用できる楽曲ライブラリから、BGMを1曲だけ使う。テロップは音なしでも伝わるようにする。
- テロップは画面の上から約3分の1の位置に置く（下部はドックとUIが隠れるため使わない。Cでは上部のカードとも重ならないように調整する）。
- 終わりのカード: 見出し＋「Habit Town｜開発中・事前登録受付中」＋「無料で事前登録」のボタン風の表示。

**ファイル命名**: `V-A1`（Aの動画）、`S-A1`・`S-A2`（Aの静止画）。UTMの `utm_content` にもこのIDを入れる。
