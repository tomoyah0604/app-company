# Habit Town — DESIGN.md

体験のコア：
> 習慣をこなすと、自分のキャラがその場所へトコトコ歩いていく。町を見ると、友達も今それぞれの場所でがんばっている。

これは創業者の依頼でG1より前に作った**品質確認用のプロトタイプ**です。目的は3Dの品質ラインを実物で確かめることで、本番のMVPではありません。

---

## 1. アートディレクション

| 要素 | 決定 | 理由 |
|---|---|---|
| 構図 | 狭い画角（FOV 30°）＋上から48°で見下ろす箱庭視点 | 正投影に近い見え方でミニチュア感が出る。奥行きの手がかりが減り、町が1画面で読める |
| 形 | 小物はすべてベベル（角の丸め）付きの RoundedBox / Extrude。尖った角はなし | 塗装済みミニチュア模型の質感。角の丸みにハイライトが乗り、立体感が出る |
| キャラ | 2.3頭身のオリジナルのちびキャラ（大きい頭、短い手足、ほっぺの赤み） | 親しみやすさ。基本形状だけで作り、既存IPのデザインは使っていない |
| 色 | パステル寄りの暖色。習慣ごとに専用の色（ジム＝ティール／読書＝オレンジ／勉強＝紫／ラン＝青） | 3Dと2D（アイコン・ラベル・ボタン）で同じ色を使い、習慣と場所の対応が1秒で分かる |
| 素材 | つや消し。roughness 0.8〜0.95、metalness 0 | 塗った木や粘土のような質感 |
| 地面 | 芝・道・広場・トラックを**1枚のCanvasTextureに描き込む** | 境界が柔らかく、Zファイティング（面のちらつき）がなく、描画1回で済む |
| 屋根 | 手続き生成した瓦テクスチャを、マテリアルの色で着色 | 単色のべた塗りに見えないようにする |

### 光と時間帯
- 端末の時計に合わせて朝・昼・夕・夜を切り替える（右上のボタンで手動でも切り替えられる）
- `tokens.ts › lighting` に、空・太陽・半球光・水の色をプリセットとして持つ。切り替えは指数補間（`1 - e^{-2.2dt}`）で約1.5秒かけて移る
- 夜は窓と街灯の発光を1.0超えのHDR値にして、そこだけBloomで光らせる。星とホタルは `env.night` に合わせてフェードインする

### ポストプロセス（入れた理由）
| エフェクト | 設定 | 理由 |
|---|---|---|
| **ToneMapping AgX** | — | HDRの発光（街灯は×5.5）を色相を崩さずに収める。ACESだと彩度の高いパステルが黄色に寄る |
| **Bloom（mipmap）** | threshold 1.0 | HDR値（街灯・窓・紙吹雪の星）だけが光る。画面全体は白っぽくならない |
| **TiltShift** | blur 0.16 / taper 0.42 | 視線を画面中央に集め、ミニチュア感を強める。reduced-motion 時と低品質時はオフ |
| Vignette | darkness 0.42 | 視線を中央に集める |
| SMAA | — | ポストプロセスを通すとMSAAが効かないため、antialiasはオフにしてこちらを使う |
| ~~SSAO / N8AO~~ | 不採用 | N8AOは three r187 と互換性がない。SSAOは法線パスが必要で、**描画が丸ごと1回増える**わりに差が小さい。ソフトシャドウと半球光で代わりにした |

## 2. 動き

| 項目 | 実装 | 値 |
|---|---|---|
| 歩行 | 道のグラフ上の最短経路（Dijkstra）を、centripetal Catmull-Rom 曲線にして弧長パラメータで移動 | 秒速2.6m（人ごとに±8%）。出だし0.5mで加速、最後の0.6mで減速 |
| 方向転換 | 角度の指数減衰 | λ=10 |
| 歩き方 | 進んだ距離に連動した位相で手足を振り、上下動・前傾・頭の揺れを足す | 歩き：振り幅0.62rad／走り：1.0rad、前傾0.2rad |
| すれ違い | 人ごとに通る位置を左右にずらす（±0.25m） | 同じ道で重ならない |
| 活動 | ジム＝ダンベルプレス＋スクワット／図書館＝座って読書（本が出る）／カフェ＝座って書く＋ときどき飲む（カップを持ち上げる）／公園＝楕円トラックを周回／広場＝見回す・伸び・9〜23秒ごとに移動 | 座る動作は時間をかけて切り替える（λ=8） |
| お祝い | 建物の押しつぶしスプリング（k=380, c=9）＋金色の衝撃リング＋紙吹雪98枚（重力・空気抵抗・終端速度でひらひら落ちる）＋バンザイジャンプ＋花が5本生える | 紙吹雪の落下は最大でも秒速1.2mに抑え、ゆっくり舞わせる |
| リアクション | ハートと星は常にカメラの方を向き、上昇しながらポンと出てポンと消える。受け取ったキャラがスプリングで跳ねる（k=160, c=9） | — |
| UI | CSS の `linear()` で物理スプリングを再現（行き過ぎ約16%） | 押すと0.08秒で反応、離すと0.45秒で戻る |
| カメラ | camera-controls、smoothTime 0.45。追従中はキャラの少し手前（縦画面で1.3m）を狙い、キャラがドックより上に来るようにする | ユーザーがドラッグしたら追従をやめる |

どのアニメーションも途中で割り込める（スプリングと減衰を毎フレーム積分する方式で、トゥイーンは使っていない）。

## 3. パフォーマンス（実測）

デスクトップ1440×900、昼、全景カメラ、キャラ10人で計測：

| 指標 | 予算 | 実測 | 備考 |
|---|---|---|---|
| ドローコール（影のパスを含む） | 100未満（プロンプト） | **558**（最適化前は1706） | 対策は下記 |
| 三角形 | 50万未満 | **31.1万** | ✅ |
| テクスチャ | — | 28 | すべて手続き生成（外部アセットなし） |
| JS（gzip） | 300KB未満 | **434KB** | ❌ R3F v9 がTHREEの名前空間を丸ごと `extend` するため、three.js が tree-shake されない |
| フレームごとのGC | ゼロ | ほぼゼロ | パーティクルは TypedArray のプール。ラベルは読み取りをまとめてから書き込む |

実施済みの最適化：
- **StaticBatch**：書くときは小さなメッシュを宣言的に並べたまま、マウント時にマテリアルごとに結合する。建物1棟で約60 → 約8ドローコール。元のメッシュは非表示のまま当たり判定だけ残すので、タップは効く
- 木・茂み・草・花・紙吹雪・ハート・ホタルはすべて `InstancedMesh`。木の揺れは頂点シェーダーで動かす
- ラベルは `drei/Html`（Reactルート10個）を使わず、DOMレイヤー1枚に毎フレーム1回だけ画面座標を投影し、重なりを順に解消する
- 解像度の自動調整：2秒ごとの平均fpsが45を切ったらDPRを段階的に下げ、1.25を下回ったら低品質に切り替える。上げ下げを4回往復したら調整をやめる
- 低スペック端末（メモリ3GB以下またはコア数4以下）は最初から低品質で始める

予算内に収めるための次の手：
1. **キャラのインスタンス描画化**（部位ごとにInstancedMeshを1つ＋インスタンスごとの色）。現在の558のうち約380がキャラなので、これだけで合計120前後まで下がる見込み
2. 影のマップ：静的な物体の影はキャッシュし、動くキャラだけを描き直す
3. バンドル：R3Fの tree-shake 可能な `extend` モードにするか、ポストプロセスをコード分割する

> 注：ヘッドレスでの確認は SwiftShader（CPU描画）で2〜6fpsしか出ないため、実機の性能は反映していない。iPhoneかミドルレンジのAndroidでの実機fps計測が残っている。

## 4. アクセシビリティと堅牢性
- `prefers-reduced-motion`：カメラの移動を即時にし、TiltShiftを切り、紙吹雪を減らし、CSSアニメーションをほぼゼロにする
- 操作はすべてDOMの `button`（キーボード・スクリーンリーダー対応）。名札もボタンで、「ハル、図書館で読書中、88日連続」のような `aria-label` を付けている
- WebGLが使えない環境では2Dのフォールバックを表示する
- `dt` を1/20秒で頭打ちにし、タブ切り替えやフレーム落ちで動きが破綻しないようにする（`?dtmax=` で上書きでき、ヘッドレス撮影用）
- セーフエリア（ノッチ）と `touch-action: none` に対応

## 5. 構成

```
src/
  tokens.ts            デザイントークン（色・素材・動き・時間帯の光）
  store.ts             zustand：人・記録・お祝い・リアクション・花・UI
  data/habits.ts       習慣の定義・友達のサンプル
  data/world.ts        配置・道のグラフ・Dijkstra・スポット・トラック・シード付き乱数
  systems/
    registry.ts        キャラとラベルの実際の位置（Reactの外で管理）
    simulation.ts      Supabase Realtime の代わり（チャンネル購読に差し替える）
  world/
    Scene.tsx          Canvas・ポストプロセス・品質の自動調整
    Environment.tsx    空・水のシェーダー・太陽・星・時間帯の補間
    Island.tsx         層状の地形＋地面に描き込むテクスチャ
    Buildings.tsx      家・ジム・図書館・カフェ・公園・広場
    Character.tsx      キャラ・歩行・ポーズ・小道具
    Nature.tsx         木・草花などの配置・花・雲・ホタル
    Effects.tsx        紙吹雪・ハート・星のパーティクルプール
    CameraRig.tsx      箱庭カメラ・追従・画面比率ごとの画角合わせ
    LabelProjector.tsx 名札の画面投影と重なりの解消
    StaticBatch.tsx    静的メッシュのマテリアル別結合
  ui/                  HUD（2D）・名札・アイコン
```
