# Habit Town（3Dプロトタイプ）

75日チャレンジを、箱庭の3Dの町で続ける習慣トラッカーの品質確認用プロトタイプ。

## 起動
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的ファイルを出力（相対パスなので、どこに置いても動く）
```

## 触り方
- 下のドックで習慣をタップ（または建物をタップ）→ 自分のキャラがその場所まで歩き、着いたら記録とお祝い
- 名札かキャラをタップ → プロフィールを開き、拍手・ハートを送れる
- 右上：時間帯の切り替え（自動・朝・昼・夕・夜）／フレンド一覧／Plus（課金導線）
- ドラッグで町を移動、ホイールかピンチでズーム、右ドラッグか2本指で回転

設計の判断、実測値、残っている課題は [DESIGN.md](./DESIGN.md) にまとめた。
