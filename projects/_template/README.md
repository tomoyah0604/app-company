# projects/_template

新しい案件を始めるときは、このフォルダを `projects/<アプリ名>/` にコピーして使う。

## 使い方
1. `_template` を複製し、案件名にリネーム。
2. `brief.md` を埋める（1秒理解テストの一文が書けるまで粘る）。
3. 司令塔ソラに「この案件を開始して」と依頼 → G0からパイプラインが回り始める。
